Context: Create a new homepage (src/routes/index.tsx) for the Memory Driver application. The design must be professional, high-converting, and strictly adhere to the styling and color palette of Evon Medics.

1. Visual Style & Branding
Apply the Evon Medics brand identity:

Color Palette:

Primary Navy: #091F38 (Black Pearl) for headers, footers, and primary text.

Accent Orange: #D4480D for primary Call-to-Action (CTA) buttons.

Backgrounds: Use a "minimalist and simple" approach with ample white space to build trust and reduce cognitive load.

Typography: Use large, legible fonts (minimum 16px) with a clear hierarchy to ensure professional readability.

Imagery: Use high-resolution device mockups or screenshots of the Memory Driver app rather than generic stock photos to resonate with users.

2. Page Structure (Based on Mockup)
Build the page using a responsive, single-column layout optimized for mobile. Use the following sections:

Header (Logo): Center the Evon Medics logo at the top as per the mockup.

Hero Section (Memory Driver):

Place a high-fidelity image or graphic representing "Mem Driv" on the left.

On the right, place a "Register" button styled with the Evon Medics accent orange.

Secondary Section (Ambassador Program):

Include a card or box for the "Ambassador Program" on the left.

Place a "Sign Up!" CTA button on the right.

Footer/Link Section (MD Link):

Add a professional text input or clear display area for the "MD Link" at the bottom as shown in the mockup.

3. Functional Requirements
Navigation: Ensure simple, intuitive navigation with clear, standard labels.

CTAs: Buttons should be "thumb-friendly" for mobile users and placed prominently "above the fold".

Accessibility: Adhere to WCAG 2.1 AA standards, including high contrast ratios and screen reader compatibility.

Responsive Design: Elements should stack vertically on mobile devices to avoid horizontal scrolling.

4. Technical Stack Implementation
Use TanStack Start for file-based routing and SSR.

Leverage Tailwind CSS (if configured) for rapid, consistent styling of buttons and layouts.

Ensure the page loads in under 3 seconds to maintain user trust.
